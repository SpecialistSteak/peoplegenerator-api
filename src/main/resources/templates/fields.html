Fields

Below are the different types of objects this API can return.


Person

FieldTypeDescription
namestringThe person's full name.
ageintegerAge in years.
jobstringJob title, Student, or Retired.
doBstringA Java Date.toString() value, including the server time zone. It is not ISO 8601.
incomeUSDintegerGenerated income in US dollars.
creditScoreintegerGenerated credit score; 0 for people under 18.
ccNumberstring or nullGenerated credit card number; null for people under 18.
marriedbooleanWhether the person is married.
hasChildrenbooleanWhether the person has children.
heightnumberHeight in centimeters.
weightnumberWeight in kilograms.
eyeColorstringEye color in uppercase.
emailstringGenerated email address.
genderstringMale, Female, or Other.
hasDegreebooleanWhether the person has a degree.
gpanumberGrade point average from 0 to 4.
bloodTypestringBlood type, including the Rh factor.
usernamestringGenerated username.
politicalLeaningnumberGenerated position on a scale from -1 (left) to 1 (right).
religionstringGenerated religious affiliation.
addressobjectThe address object described below.

Address

FieldTypeDescription
streetAddressstringGenerated street address.
citystringCity selected from the bundled world-cities data.
statestringState or province selected within the country.
countrystringCountry name.
zipstringGenerated postal code.
geonameIdintegerGeoNames ID selected within the country, or -1 if unavailable.
phoneNumberstringCountry calling code and generated digits.
ipAddressstringGenerated IPv4 address.
countryCodestringTwo-letter country code.

Life story

FieldTypeDescription
personobjectA complete person object.
lifestorystringA paragraph assembled from the person's fields.
