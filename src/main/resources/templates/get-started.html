Get started

Run the server locally, then try GET /api/person/ for one profile. No API key is required. Every request generates new data.


Requesting 100 people

These examples use the local server. Bulk responses always use gzip. Browsers and Python requests decompress them automatically; Java HttpClient needs a GZIPInputStream.

const response = await fetch('/api/person/100'); if (!response.ok) throw new Error(`HTTP ${response.status}`); const people = await response.json(); console.log(people);
import java.net.URI; import java.net.http.*; import java.io.ByteArrayInputStream; import java.nio.charset.StandardCharsets; import java.util.zip.GZIPInputStream; public class Main { public static void main(String[] args) throws Exception { var request = HttpRequest.newBuilder() .uri(URI.create("http://localhost:8080/api/person/100")) .GET().build(); var response = HttpClient.newHttpClient().send( request, HttpResponse.BodyHandlers.ofByteArray()); if (response.statusCode() != 200) { throw new IllegalStateException("HTTP " + response.statusCode()); } try (var gzip = new GZIPInputStream(new ByteArrayInputStream(response.body()))) { System.out.println(new String(gzip.readAllBytes(), StandardCharsets.UTF_8)); } } }
import json import requests response = requests.get('http://localhost:8080/api/person/100', timeout=30) response.raise_for_status() print(json.dumps(response.json(), indent=2))

Life story

GET /api/lifestory/ returns an object with a full person object and a lifestory string. The story is assembled from that person's fields using a text template.
